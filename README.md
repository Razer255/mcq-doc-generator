# 🚀 MCQ to DOCX Generator

A powerful web-based tool that converts structured Multiple Choice Questions (MCQs) into a properly formatted `.docx` file — built for educators, interns, and organizations.

---

## 🌟 Why This Tool?

This tool was created to simplify the process of converting MCQs into structured Word documents for:

- 📚 Academic use
- 🧑‍💻 Internship projects
- 🏢 Organizational assessments
- 📝 Question bank creation

It is actively being used by interns and team members inside our organization.

---

## ✨ Features

- ✅ Auto-detect numbered questions  
- ✅ Strict 4-option validation  
- ✅ Real-time Valid vs Invalid detection  
- ✅ Upload progress bar  
- ✅ Smart Answer conversion (A → 1, B → 2, etc.)  
- ✅ Clean DOCX structured output  
- ✅ Malformed MCQ detection  
- ✅ Live question counter  

---

## 🖥️ Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript  
- **Backend:** Node.js, Express  
- **Document Engine:** `docx` npm package  
- **Upload Handling:** Multer
